# 🍽️ Prajna Restaurant

A modern luxury restaurant website built using the MERN Stack with a premium dark-gold theme, responsive design, and full-stack architecture.

## 🚀 Live Demo

Frontend: https://prajna-restaurant.vercel.app/

## 🛠️ Tech Stack

### Frontend

* React.js (Vite)
* CSS
* Glassmorphism UI
* Playfair Display
* Cormorant Garamond

### Backend

* Node.js
* Express.js

### Database

* MongoDB Atlas

### Deployment

* Frontend: Vercel
* Backend: Render

## ✨ Features

* Responsive restaurant website
* Modern luxury UI design
* Smooth animations
* MERN stack architecture
* MongoDB database integration
* Fully deployed application
